# P-38i — Live smoke + docs for delegation

Card: live smoke tests for the delegation loop (P-38b/c/d, surfaced by
P-38g) against a real model server, plus the README's Try-it section gains
the `harness.task.delegate` grant and its limits.

## What was done

- `harness-cli` `tests/live_delegate.rs` (new, `#[ignore]`d like
  `exit_h1.rs`; run with `RUSTYHARNESS_EXIT_ENDPOINT` and
  `RUSTYHARNESS_EXIT_MODEL` set,
  `cargo test -p harness-cli --test live_delegate -- --ignored --test-threads=1`):
  a fixture workspace buries one CURRENT codename
  (`GREEN-FALCON-91`) under a decoy (`OLD-SPARROW-07` in
  `docs/archive.txt`), and the task tells the model to hand the searching
  to a helper if one is granted.
  - `live_delegate_answers_fixture_question_and_audits`: with the
    delegate grant, the run ends `submitted` (exit 5,
    `NothingChecked`), the submitted note holds the codename, the
    parent journal holds `ChildRun` records with the helper's carve
    (`limits.steps` within the 15-step cap) and spend, and an anchored
    `replay` prints `child run …: anchored, no divergence` per helper
    plus "The anchor matched the journal's chain head.".
  - `live_delegate_vs_inline_usage_recorded`: runs the same task with
    and without the grant, asserts both submit the codename, the
    inline journal has no `ChildRun`, both replays anchor-match with
    children audited (the default `ChildAudit`), and writes a TSV
    (parent steps/tokens, helper runs/steps/tokens per variant) to
    `CARGO_TARGET_TMPDIR/live-delegate-usage.tsv` for this note.
  - `readme_mentions_delegate_grant_limits` (not ignored): pins the
    Try-it wording below (matched over whitespace-normalized text, so
    reflowing cannot break it).
- `README.md` (Try-it only): a new paragraph after the budgets one —
  delegation needs `harness.task.delegate` in the task grants, never by
  default; helpers are read-only (read/list/search/outline — no edits,
  no commands, no helper of its own), at most 5 helpers per run, each
  carved at most 15 steps, 200 000 tokens, 10 minutes; the report is
  untrusted input; `replay` audits the helpers with the run. Prose
  only, no fenced command blocks, so `readme_quickstart_commands_exist_as_verbs`
  stays green.

## Design questions raised

1. The live tests reuse `exit_h1`'s endpoint/model environment
   variables rather than adding new ones: one local server serves both.
2. The usage TSV goes to `CARGO_TARGET_TMPDIR` (and `eprintln!`), not
   into the repo: measured numbers are quoted into this note by hand,
   not generated at gate time.
3. The run id is read from the stderr line that *starts with* `run `
   (`run <id> attempt 1: stopped …`): with helpers running, `[helper]
   started (run <id>, …)` lines also name run ids, so a substring
   search would find the wrong one.
