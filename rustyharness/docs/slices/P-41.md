# P-41 — Seatbelt live-probe robustness (retry once, scale the sweep deadline, record the attempts)

## What landed

- `crates/harness-sandbox/src/confine_spawn.rs`:
  - The frame's `lim` line gains an optional fifth field: the sweep
    deadline in whole seconds. The stub bounds it to 1-30 s (`exit 91`
    outside, fail-closed) and falls back to the reviewed 3 s when the
    field is absent, so old 4-field frames (the conformance tests'
    nested-stub fixture, which never reaches the frame) stay valid and
    the conformance suite is untouched, as the slice card asks.
  - `SWEEP_GRACE` (5 s) is replaced by `SWEEP_DEADLINE` (3 s, the default
    a call asks for) plus a `SWEEP_GRACE_MARGIN` (2 s): the grace for a
    call is its own sweep deadline plus the margin, so the base grace is
    still 5 s (3 + 2, as reviewed) and a retried probe's 9 s sweep is not
    cut short by the harness. `Running` records the deadline it was given
    and names it in the `unconverged` report ("... within the sweep
    deadline (9 s)"), so a refusal says which deadline ran out.
- `crates/harness-sandbox/src/seatbelt.rs` — the attempt schedule
  (`probe_with_retries`, rewritten; H2f's total retry budget
  `PROBE_BACKOFFS_MS` = 2 is unchanged, all retry reasons share it):
  - A sweep that ran out of its deadline (`sweep`/`proc-sweep` observing
    "would not die within the sweep deadline") is retried ONCE, asking
    the stub for a TRIPLED deadline (3 s -> 9 s).
  - A probe killed by a signal before it could report (`run`,
    `mem-applied`, `proc-limit` observing `Signaled(n)`) is re-run once,
    at the same deadline; a second failure of the same kind is final.
  - `load_shaped` (H2f) keeps exactly its old arms for spawn failures and
    `run` timeouts; the sweep arm moved to the new `sweep_timed_out`.
  - Every escape is final at once, whatever came before: `Confirmed`
    with no kill (the setsid'd process survived a *finished* sweep), a
    mid-run canary, a stub that died with no report, the network, the
    write, the memory bound. A timeout earns its retry; an escape the
    retry finds is still the answer.
  - The witness now records the attempt count and the last attempt's
    sweep deadline: `observations_digest` hashes
    `attempts=<n> sweep-deadline=<s>s` into the probe digest, so an
    audit replay comparing digests can tell a retried probe from a clean
    first-attempt one. The digest's other inputs are unchanged.
- `scripts/ci/purity.sh`: **`confine_spawn_sha256` re-pinned to
  `47e355ba9a54d280ca33de184f923546992b6ef9de5ccf8083598b4e29c431a3` in
  the same commit as the confine_spawn.rs change** (the card's loud
  note). `purity.sh` and `purity-selftest.sh` (112 cases) pass with the
  new pin; the selftest's planted confine mutations (start canary
  removed, per-pass canary weakened, foreign program) still refuse.

## Interpretations and notes for the manager

- "Retried once with 3x" is implemented as one extra attempt with a
  tripled *stub sweep deadline*; the probe run's 20 s wall clock is not
  scaled (a slower machine is what the sweep deadline is for; the wall
  clock bounds a hung probe).
- A signal death retried does not consume the timeout's 3x: the classes
  are independent, the total budget (2 retries) is shared, so worst case
  stays 3 attempts.
- The witness records the attempts via its digest only (the `Conformed`
  struct is unchanged; the run header already journals `probe_digest`).
  If the manager wants the attempts as a *named* journal header field
  instead of a digest commitment, that is a driver/header change outside
  this crate and this slice.
- 4.1's loop rules (journal event, `audit` recomputation,
  `assert_audit_clean`, `context_format`) do not apply: nothing
  loop-visible changes — same header fields, same context rendering.
- The probe is not observably slower on the happy path: one attempt,
  same deadline, same digest *shape* (values differ from the old pin by
  design — a witness minted before this change is not comparable, which
  is fine: a witness is host-and-version-local and re-minted per run).
