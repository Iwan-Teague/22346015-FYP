# P-07 — defaults: state root, workspace, user config; `profile init`

Branch `w/P-07`. No new dependencies; `Cargo.lock` unchanged; library APIs
(`harness-run`, `harness-model` public surface) unchanged except the added
`OpenAiCompatible::list_models`.

## What was built

- **User config** (`crates/harness-cli/src/config.rs`): `<config dir>/config.json`,
  optional, strict JSON (`deny_unknown_fields`, duplicate keys refused via
  `strict_json::parse`). Keys: `endpoint`, `profile`, `policy`, `state_root`,
  `approver`. Every command-line flag overrides the config (`config::value`).
  The config is read only from the user config dir, never from the workspace
  (`config_in_workspace_is_never_read`).
- **Locations** (fail-closed readings of "per-user"):
  - `$RUSTYHARNESS_CONFIG_HOME` / `$RUSTYHARNESS_STATE_HOME` when set — must be
    absolute, else refused (exit 4).
  - macOS: `$HOME/Library/Application Support`; other unix:
    `$XDG_CONFIG_HOME` / `$XDG_DATA_HOME` (absolute, non-empty = set; an empty
    value counts as unset per the XDG spec), else `~/.config` / `~/.local/share`.
  - Windows or no usable `HOME`: `Ok(None)` — "no config / no default state
    root here", not an error; the flags become required (usage exit 2).
- **Default `state_root`**: `<state home>/rustyharness`, created 0700 when
  missing (parents created as needed; an existing dir is left as it is), used
  by `run`/`resume`/`replay` when neither flag nor config names one. A
  flag/config-provided state root is never created — it must exist, as before.
  It is locality-checked like any other
  (`default_state_root_refused_if_not_local`: exit 5, nothing written under it).
- **Default workspace**: `--workspace` absent → the current directory
  (`default_workspace_is_the_current_directory`); a cwd that cannot be
  determined is fail-closed (exit 5, not a silent other directory).
- **Approver**: config `"approver": "none"` suppresses the terminal approver
  even at a tty; `"terminal"` (default) keeps today's behaviour. An approver
  given to the library (`Cx`) still wins.
- **`profile init --endpoint URL [--out file]`** (`cmd_profile.rs`):
  `GET /v1/models` (new `OpenAiCompatible::list_models`, typed errors; no
  server-claims side effect), then:
  - tty: numbered list on stderr, one stdin line, `resolve_choice` (exact id or
    1-based number; anything else refused — no guessing);
  - not a tty: the single listed model is picked automatically; several listed
    → refuse with "run from a terminal" (exit 1).
  Writes `Profile::conservative_default(model)` rendered through the getters
  (`profile_version` 1, `grammar "none"`, unset optionals omitted), re-parsed
  and compared by `content_sha256` before anything is written (render drift →
  exit 5, nothing written). File mode 0600 (unix). Default `--out` is
  `<config dir>/profiles/default.json` (dir created 0700). Then the same smoke
  eval as `profile check`: pass → the stamp is inserted, re-parsed, verified
  (`validated()`), the file rewritten and the stamp JSON printed (exit 0);
  fail → the file stays unstamped, exit 1
  (`profile_init_stamps_only_on_pass`).
- **USAGE** gained the `profile init` line and a Defaults paragraph; the
  `usage_text_unchanged` golden was updated deliberately.

## Exit codes (non-gate `profile init`)

options 2 · endpoint refused 4 · connect/GET/cannot-determine/write 5 ·
list empty / choice refused / unusable model id / no stamp 1 · success 0.
Gate children load the config once in `dispatch` and turn a bad config into
`refused(UNREADABLE_INPUT)` (exit 4) with the report line never missing.

## Tests

`crates/harness-cli/tests/config.rs` (all in-process, one `ENV_LOCK` mutex —
env vars and cwd are process-global; no tty-dependent paths):

`config_flags_override_file`, `config_in_workspace_is_never_read`,

(unknown key, relative path, empty endpoint, bad approver, duplicate key) and
`resolve_choice` in `cmd_profile.rs`.

## Not done here (by design)

- Library `harness-run` reads no config; journals/audits unchanged.
- Windows config/state dirs wait for their spike; `Ok(None)` fails over to
  flags, and without a state root the verbs say so (usage exit 2).
